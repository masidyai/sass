masidy
masidy is a modern, production‑ready SaaS boilerplate designed to help developers build scalable, multi‑tenant applications with speed and confidence. It includes robust authentication, workspace and project management, analytics, and a clean, responsive UI—everything you need to launch your SaaS product faster.

Built with best‑in‑class technologies and clean architecture principles, masidy provides a solid foundation for long‑term maintainability and growth.

🚀 Features
⚡ Next.js 14 — App Router, layouts, server components, and optimized performance

🛡️ Authentication — Secure, extensible auth with email, OAuth providers, and session management

🏢 Multi‑Tenancy — Tenant‑aware routing and middleware for isolated workspaces

📊 Analytics Dashboard — Track usage, performance, and key business metrics

🗂️ Workspace & Project Management — Organize teams, projects, and collaboration flows

🔌 API Integrations — Clean, scalable API structure for internal and external services

🎨 Tailwind CSS — Fully responsive, modern UI with customizable components

🗄️ Prisma ORM — Type‑safe database access with migrations and schema management

🧩 Modular Architecture — Clear separation of concerns for easy extension

🧪 Developer‑Friendly — TypeScript, ESLint, Prettier, and ready‑to‑use scripts
