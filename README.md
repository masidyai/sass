# masidy

masidy is a modern, production-ready SaaS boilerplate for building scalable, multi-tenant web applications. It features robust authentication, analytics, project and workspace management, and a beautiful, responsive UI. masidy is designed for rapid development, maintainability, and best practices.


## 🚀 Features

- ⚡ **Next.js 14** — App directory, file-based routing, layouts
- 🛡️ **Authentication** — Secure, extensible auth (email, OAuth, etc.)
- 🏢 **Multi-Tenancy** — Middleware for tenant isolation
- 📊 **Analytics Dashboard** — Visualize usage and key metrics
