# masidy

masidy is a modern, full-stack web application built with Next.js, TypeScript, and Tailwind CSS. It features a modular architecture, robust authentication, analytics, project management, and a beautiful, responsive UI. masidy is designed for scalability, maintainability, and ease of use, making it ideal for SaaS platforms, dashboards, and developer tools.

## Features

- **Next.js 14**: App directory structure for scalable routing and layouts
- **TypeScript**: Type-safe codebase for reliability and maintainability
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development
- **Authentication**: Secure user authentication and session management
- **Multi-Tenancy**: Middleware for multi-tenant support
- **Project & Workspace Management**: Organize projects and workspaces efficiently
- **Analytics Dashboard**: Visualize usage and key metrics
- **API Integrations**: Support for PayPal, Vercel, and more
- **Prisma ORM**: Type-safe database access
- **Component Library**: Reusable, accessible UI components
- **Responsive Design**: Mobile-first, adaptive layouts

## Folder Structure

- `app/` - Application routes, layouts, and pages
- `components/` - Reusable UI and feature components
- `hooks/` - Custom React hooks
- `lib/` - Utility functions and API integrations
- `middleware/` - Custom middleware (e.g., multi-tenant)
- `prisma/` - Database schema and migrations
- `public/` - Static assets
- `styles/` - Global styles
